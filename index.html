ThresholdGuard

Verification that scales with ambiguity. Settled early, escalated near the limit, inconclusive when it stays unclear.

The question is different

Most verification asks is this true? This one asks how far from the limit is it? That is the question you need when a false PASS is expensive: an SLA cap, a latency budget, a concentration limit, an emissions ceiling.

The decision

Readings from the tier's sources give low, high and spread. They are trusted only when enough independent sources agree and agree tightly enough:

trustworthy = n >= min_agree[tier]  and  spread <= grey
directionPASSFAILotherwise
MAX (a cap)high <= thresholdlow > thresholdstraddles → escalate
MIN (a floor)low >= thresholdhigh < thresholdstraddles → escalate

A PASS needs even the worst reading to clear the limit; a FAIL needs even the best reading to breach it. Anything in between gets more work, not a coin flip. The margin reports how far from the boundary the decision landed.

The ladder

Up to three tiers of sources, assessed after every read, so the check settles the moment the evidence becomes decisive:

tier 1  decisive? -> PASS / FAIL     else ESCALATED
tier 2  decisive? -> PASS / FAIL     else ESCALATED
tier 3  decisive? -> PASS / FAIL     else INCONCLUSIVE

INCONCLUSIVE is a real answer: this evidence cannot settle it.

What counts as a measurement

The model is asked one narrow question — what value of FIELD, in UNIT, does this page report? — and nothing else calls a model. A reading is dropped, with a reason, unless all of these hold:

checkrejects
value statednot_stated
value parses as a numbernot_numeric
unit matches the checkwrong_unit
number occurs in the page as a whole tokennot_in_source
unit is written in the pageunit_not_in_source

Whole-token matching is what stops 50 from being confirmed by a page that says 1500. A rejected reading is not a failure — the tier simply cannot reach its bar from that source, and moves on.

How to verify

  1. Open the Bradbury Explorer link above and read get_check("1").
  2. Read get_readings("1", 0) to see each measurement and whether it was accepted.
  3. Clone the repository and run python -m pytest tests/direct -q.
